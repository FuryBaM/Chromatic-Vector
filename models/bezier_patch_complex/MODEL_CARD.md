# PatchBezier Complex

Отдельные экспериментальные веса с архитектурой PatchBezier-v1. Обучение начато с ONNX из `chromatic_vector/assets/bezier_patch_v1`. Веса загружаются через `--neural-model` и выполняются локально в OpenCV DNN.

В наборе 14 400 синтетических участков. Треть сохраняет исходное распределение. Дополненная часть включает отверстия, узкие ленты, соседние вогнутые кромки и Т-стыки. Стык у края участка может оставлять центральную часть пригодной для аппроксимации. Стык, пересекающий её, обучает выход отказа. Портрет использовался только для проверки экспорта.

```bash
python training/train_bezier.py --complex \
  --init-onnx chromatic_vector/assets/bezier_patch_v1/model.onnx \
  --train 14400 --epochs 20 --lr .00027 --threads 4 \
  --output artifacts/neural-complex/trained

python training/check_complex_shapes.py \
  --model models/bezier_patch_complex/model.onnx \
  --output artifacts/neural-complex/stress
```

`metadata.json` содержит контрольную сумму, исходные и итоговые метрики на одинаковых выборках, а также историю валидации. В пресете `poster` проверка пересечений и оценка резких поворотов работают на целом контуре. При отказе трассировщик сохраняет классическую кривую.

На 1 600 контрольных участках модель при рабочем пороге 0,80 распознала 80,2% опасных стыков против 3,8% у исходных весов. Доля ошибочных отказов на плавных участках выросла с 1,5% до 3,1%. На дополнительной выборке из 1 600 участков с seed 391745 распознавание опасных стыков составило 85,5% против 1,7%.

На четырёх контрольных SVG сохранились число связных деталей и отверстия. На этих формах экспорт использовал классические кривые. На портрете в финальный SVG вошло 12 нейросегментов против 89 у исходных весов с теми же защитами. Точность совпадения краёв при допуске 1 px составила 0,816 против 0,818. Это более консервативный экспериментальный вариант.
